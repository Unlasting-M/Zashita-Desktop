# 验证范围

## 自动验证

`npm test` 会先构建页面，再验证：

- 七条真实俄语案例：三条老师无问号提问命中，四条答辩人短句被过滤。
- 五条上下文与专业缩写修复，检索词和双语输出格式。
- 44.1/48kHz → 16kHz 连续 PCM 重采样、final 去重、中间结果不触发问答。
- 新题不替换阅读中的答案，检索结果含真实匹配片段。
- Qwen 配置、鉴权、音频转发、结束冲刷、错误与重复启动处理。
- 本地服务的 Host / Origin / 会话凭证、WebSocket 握手、请求大小与静态文件限制。
- 密钥保存、重建实例恢复、加密失败保留旧值、清除。
- 指定麦克风使用 exact 设备 ID；系统音频的屏幕轨道立即停止且不发送画面。
- PDF 流式读取兼容与错误释放。

`npm run test:desktop` 启动真实 Electron 窗口和 Windows 系统加密，但使用隔离数据目录、假 Key 及模拟问答。验证 PDF / DOCX / TXT 导入、设备和术语跨页及重启保留、密钥重启恢复、上下文缩写、后台排队不覆盖当前答案、1080px 布局，以及不请求外部托管网址。

设置 `ZASHITA_QA_EXE` 为 `release/win-unpacked/Zashita.exe` 可对打包程序运行同一流程。截图与结果保存到忽略提交的 `output/desktop-qa/`。

## 仍需真实环境确认

自动测试禁止真实音频采集，不使用用户密钥，不调用付费云 API。因此不声称已在用户麦克风、UU 虚拟音频、实际会议播放设备上完成收音验收，也不声称已验证用户云账户权限或俄语识别准确率。安装后使用自己的 Key 与设备检查实际识别、系统音频、网络重连和不同显示缩放。

Windows 10 的常规窗口与 Windows 11 桌面磨砂效果依赖系统与显卡设置。当前包无代码签名。数据迁移仅支持本项目网页 JSON 格式，不读取旧 1.x 专有数据库。
