# Zashita Desktop

[简体中文](README.md) · [English](README.en.md)

Самостоятельное приложение для Windows, помогающее подготовить ответы на вопросы во время защиты на русском языке. Оно распознаёт речь, выделяет вопросы с учётом контекста, ищет подходящие фрагменты работы и формирует ответы на русском с китайским переводом. Интерфейс приложения — на китайском языке.

## Установка

Скачайте установщик x64 или переносимую версию в [Releases](https://github.com/Unlasting-M/Zashita-Desktop/releases). Аккаунт GPT, размещённый на платформе сайт, Python и локальная модель распознавания не нужны. Для облачных функций необходимы интернет и собственные ключи Alibaba Cloud Bailian и DeepSeek.

Приложение предназначено для Windows 10/11 x64. Прозрачный акриловый фон доступен в Windows 11 22H2 и новее, если системные эффекты поддерживаются. Текущие сборки не подписаны цифровой подписью.

## Работа с приложением

1. В настройках введите оба ключа и нажмите «保存密钥» (сохранить). Регион Bailian должен соответствовать ключу: Пекин или Сингапур. Используется `qwen3-asr-flash-realtime` с русским языком.
2. Выберите микрофон либо системный звук для онлайн-конференции. Выбор сохраняется сразу; временное отключение устройства не сбрасывает его.
3. Импортируйте PDF с текстовым слоем, DOCX, UTF-8 TXT или Markdown: до 20 МБ на файл и до 250 страниц PDF. Сканированные документы сначала нужно распознать через OCR.
4. Нажмите «开始收音» (начать запись). Вручную переключайте роль: преподаватель или отвечающий. Несколько голосов в одном источнике автоматически не разделяются.
5. Новые вопросы добавляются в очередь, не заменяя текущий ответ. Для перехода нажмите «下一题». Можно также ввести вопрос вручную или повторно обработать фрагмент расшифровки.

Система учитывает вопросы без знака вопроса, частицу «ли» и просьбы вроде «объясните». В модель передаются пять последних фрагментов контекста; сокращения раскрываются только при наличии основания в предыдущем тексте. Рядом с ответом доступны использованные фрагменты работы.

## Данные и перенос

Данные сохраняются в `%APPDATA%\ZashitaDesktop`. Ключи хранятся отдельно с системным шифрованием Windows через Electron `safeStorage` и не входят в резервную копию JSON. Звук отправляется напрямую в Alibaba Cloud, а вопросы, контекст и найденные фрагменты — в DeepSeek. Встроенный сервер слушает только `127.0.0.1:18789` и проверяет временный ключ сеанса.

JSON-копию из веб-версии Zashita можно импортировать через настройки. База старой Windows-версии 1.x несовместима: материалы нужно импортировать заново. Старая установка не изменяется. При сворачивании сбор звука продолжается; сон, блокировка, потеря сети или устройства могут его прервать.

Это новый проект с полным исходным кодом на основе веб-клиента автора. Он не содержит прежний исполняемый файл Copy InterviewDog, закрытый сервер, декомпилированные модули или локальные модели Whisper.

## Сборка

Понадобятся Windows, Node.js 24 LTS и npm:

```powershell
npm ci
npm run build
npm start
npm test
npm run test:desktop
npm run package:win
```

Результаты находятся в `release/`. При первой сборке загружаются Electron и инструменты упаковки. Проверка `test:desktop` использует отдельный профиль, тестовые ключи и локальную имитацию модели, без записи реального звука и платных запросов. Микрофон, системный звук и облачный аккаунт требуют отдельной проверки. Подробнее: [проверки](docs/VALIDATION.md).
